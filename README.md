# Erimsah Olut — Portfolio

Personal portfolio site, built with React, TypeScript, Vite, Tailwind CSS and Framer Motion.

All graphics are drawn in code (SVG / canvas). Fonts are self-hosted from Fontsource (SIL Open Font License).

## Develop

```bash
npm install
npm run dev
```

Site content lives in `src/data.ts`.

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages via `.github/workflows/deploy.yml`.
